title: One door for the integral
---
The work of the week left five names for one idea (`integrate`, `integrate_with_error`, `quadrature`, `quadrature_checked`, `gauss_kronrod`) and three orders of template parameters (`limit<N>`, `quadrature_checked<T, N>`, `limit_at_infinity<N, T>`), measured as friction while the way the library is used was audited; the names were days old and used nowhere but their own tests, so they were folded, not wrapped. `integrate(f, domain, options)` is the door: the domain is a type that carries its scalar (`Finite<T>`, `HalfLine<T>`, `WholeLine<T = double>`, so `WholeLine{}` and `WholeLine<Real50>{}`), the scalar is always deduced, and the answer is always an `IntegralResult`. `checked(domain)` puts the p-test in the type instead of a flag, so a function that is not generic over the scalar never has to compile the series path (a flag would have made every generic function using `std::exp` fail to compile, since deciding whether f is callable on a Series instantiates its body). `IntegralOptions{.tolerance, .max_levels, .method = Auto|DoublyExponential|GaussKronrod|Simpson, .witness}`: a finite-interval rule asked of an infinite domain is `Failed`, not a guess. `witness` is the idea the audit proposed first: run a second rule that shares no node with the first (Gauss-Kronrod, or the doubly exponential rule when Gauss-Kronrod is the primary, or Simpson beyond long double) at its own strictest tolerance, and call the answer `Suspicious` where the two differ by more than their estimates plus a few ulps -- so x^0.7 by Simpson at 1e-3, which one rule calls Converged with a true error several times its estimate, is caught. Whether Gauss-Kronrod's constants suffice is a property of the scalar (`gk_capable`: float, double, long double, a Dual or Series of them), not of its epsilon, which a multiprecision number cannot give at compile time -- found by a build that failed on Real50. `integrate(f, a, b)` of calculus.hpp, the value alone by Simpson, stays and is the same rule as `{.method = Method::Simpson}`. Likewise `limit(f, AtInfinity{})` replaces `limit_at_infinity`: the point carries its scalar, so `limit` reads the same at a number and at infinity. Not done: Gauss-Kronrod and Simpson on an infinite domain, the witness on an infinite domain, `integrate_surface`.
